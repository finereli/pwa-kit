# theme

Dark mode (with the before-first-paint inline snippet) and accent-derived palettes for apps that let the user pick a colour. `lib/theme.ts` → `shared/lib/`; copy the inline `<script>` from its header comment into `index.html`. Spec: `reference/visual.md`. Verify: toggle dark with a saturated accent → buttons legible, backgrounds tinted not neon; reload → no white flash.
